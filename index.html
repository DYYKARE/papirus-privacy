3. Verilerinizi Nerede Saklıyoruz

Verileriniz Supabase altyapısında saklanır (Postgres veritabanı + Storage). Tüm veri iletimi TLS şifrelemesi ile yapılır. Veritabanında Row Level Security (RLS) aktiftir; yani sadece siz kendi verilerinize erişebilirsiniz, başka kullanıcılar göremez.

4. Üçüncü Taraf Servisler

Papirus, hizmeti sağlamak için aşağıdaki üçüncü taraf servisleri kullanır:

  • Supabase — Veritabanı ve kimlik doğrulama. Gizlilik Politikası
  • Google Books API — ISBN ile kitap bilgisi getirmek (yalnızca sorgu gönderilir, kişisel veri paylaşılmaz). Gizlilik Politikası
  • Open Library — Alternatif kitap bilgisi kaynağı. Gizlilik Politikası
  • Sentry — Çökme raporları ("diagnostics") için. Kişisel veri içermez, yalnızca teknik hata bilgisi. Gizlilik Politikası
  • Google Sign-In — Opsiyonel Google ile giriş için. Gizlilik Politikası
  • Expo / EAS — Push bildirim altyapısı. Gizlilik Politikası

Papirus — Privacy Policy

Last updated: 30 May 2026 · Version 1.0

This privacy policy explains how the Papirus mobile application (package: com.papirusapp.app) collects, processes, stores and protects user data. By downloading and using the app, you accept this policy.

1. Data Controller

Developer: Yusuf Yalçın (individual developer)
Contact email: dyyalcin90@gmail.com
Application: Papirus — Personal Library

2. Data We Collect

Papirus collects only the minimum data needed to provide the service:

  • Email address — required for account creation
  • Display name — optional, for profile
  • Profile picture — optional
  • Book list — books you add
  • Notes and quotes — content you create
  • Reading sessions — pages you mark as read
  • Push notification token — optional, for notifications
  • Crash reports (Sentry) — technical diagnostics only

What we don't collect

Location, contacts, SMS, health data, financial info, advertising IDs.

3. Where We Store Data

Data is stored on Supabase infrastructure (Postgres + Storage). All transit is TLS encrypted. Row Level Security is enabled — only you can access your own data.

4. Third Parties

  • Supabase — database & authentication
  • Google Books API — ISBN lookups
  • Open Library — ISBN lookups (fallback)
  • Sentry — crash diagnostics only
  • Google Sign-In — optional sign-in
  • Expo / EAS — push notification infrastructure

5. Data Retention

Data is kept as long as your account is active. When you delete your account (Profile → Delete Account), all your data is permanently and irreversibly deleted within 30 days, including from backups.

6. Your Rights (GDPR + KVKK)

You have the right to access, rectify, delete, export and object to processing of your data. Use the in-app delete option or email dyyalcin90@gmail.com. We respond within 30 days.

7. Children's Privacy

Papirus is designed for users aged 13+. We do not knowingly collect data from children under 13.

8. Security

All transit uses HTTPS / TLS 1.2+. Passwords are hashed (one-way). However, no internet transmission is 100% secure.

9. No Ads, No Tracking

Papirus shows no advertisements and does not track user behavior.

10. Changes

This policy may be updated. Significant changes are communicated via in-app notification or email.

11. Contact

For any privacy-related question or request: dyyalcin90@gmail.com
